## 验证边界

- 没有对真实账号执行创建、修改、删除、加词或提前复习。这些工具按官方 schema 实现并做本地请求测试，尚未验证每个写接口的实际业务结果。
- 其他读取接口尚未逐一真实调用。
- 当前 chat 不能热加载新安装工具；需要新开 chat 后验收桌面自然语言调用。
- Linux、macOS、其他 MCP 客户端、ChatGPT 网页/手机端未实机验证；本地进程不能直接运行在网页/手机端。
- 本地速率控制按进程计数，没有共享账号全局计数，也没有持久化每天创建内容的计数；官方仍会执行账号限制。

## 本机旧 CLI 兼容性

PATH 中 codex-cli 0.141.0 无法解析此机器桌面版配置中的 features.context_management 表，而且未发现本仓库插件。最终使用正在运行的 Codex Desktop 自带 CLI 0.160.0 完成安装，未更改全局配置。

如果自己的 CLI 遇到相同现象，可使用桌面版自带 CLI；不要照抄修改全局配置。仓库安装步骤适用于支持本地插件 marketplace 的较新 CLI。
